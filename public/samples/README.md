# Forge sample CAD

## as1-bracket-assembly.stp

The CAx-IF "AS1" test assembly (STEP AP214, Open CASCADE export, 433 KB): a base plate, two L-brackets each fastened with
three bolts and nuts, and a rod held by two nuts. 18 solids with names (plate, l-bracket, bolt, nut, rod), sub-assemblies
(l-bracket-assembly, rod-assembly) and colours. Units are millimetres (about 200 x 84 x 150 mm).

- Origin: CAx Implementor Forum (CAx-IF) STEP test library, https://www.cax-if.org/cax/cax_stepLib.php
  (AS1 is a public interoperability test model, freely distributed for testing STEP implementations).
- Copy taken from the occt-import-js repository test files, `test/testfiles/cax-if/as1-oc-214.stp`
  (https://github.com/kovacsv/occt-import-js, distributed there under that repository's LGPL-2.1 license,
  with `source.txt` pointing to the CAx-IF library). The file is unmodified apart from the name.

The Studio "Try the sample" button loads this file.
